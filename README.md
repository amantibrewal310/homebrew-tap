# homebrew-tap

Homebrew casks for my Mac apps. Apple Silicon only.

| App | Install | Needs |
|---|---|---|
| [NotchCove](https://github.com/amantibrewal310/NotchCove): a drop shelf that lives in the MacBook notch | `brew install --cask amantibrewal310/tap/notchcove` | macOS 14 (Sonoma)+ |
| [Accio](https://github.com/amantibrewal310/Accio): a menu bar manager that hides items and brings them back on demand | `brew install --cask amantibrewal310/tap/accio` | macOS 26 (Tahoe)+ |

Accio isn't notarized, so macOS blocks its first launch: open it once, then click **Open Anyway** in
System Settings → Privacy & Security.
